# Margins — الخطة المبسّطة (المرجع)

## الأقسام (الشريط السفلي، من اليسار)
جهازي (قراءة دون إنترنت) · متابعة · [المنزل: الدائرة الوسطى = الأونلاين] · حسابي · الإعدادات (فيها تسجيل دخول Google/Drive).

## النموذج
مكتبة (حساب) ← رفوف (الرف = رواية) ← فصول (ملفات). الكتاب المباشر = رف بفصل واحد. الفصل: مسودة / منشور.
كل ما يُنشر أونلاين عام. تُحذف كلمة السر والأصدقاء والحظر وأنماط الخصوصية.

## البوستات
نص + صورة واحدة (لا فيديو، لا تعليقات). لمن عنده رف واحد على الأقل. منشن لرفوفه هو فقط. إعجاب وعدم إعجاب علنيان.

## المتابعة والنجمة
متابعة المكتبة: الرفوف المنجَّمة فقط (افتراضي) / الكل / لا إشعارات. "لا إشعارات" تلغي النجمة. إلغاء المتابعة يزيل النجوم. تنجيم رف يتابع صاحبه تلقائيًّا. رفع عدة فصول = إشعار مجمَّع واحد.

## القراءة والتقييم والترتيب
- قراءة = سجل واحد لكل (مستخدم، فصل) مدى الحياة.
- تقييم الفصل 1–10، صوت واحد لكل مستخدم (ويشترط فتح الفصل — مقترح)، لا تقييم لرفك. لا تقييم مستقل للرف.
- تقييم الرف المرجَّح = v/(v+m)·R + m/(v+m)·C (m=10). درجة "الأفضل" = المرجَّح × log10(1+القرّاء).
- قوائم: المنتشر حديثًا (قرّاء جدد 7 أيام) · الأكثر قراءة · الأعلى تقييمًا · الأفضل.
